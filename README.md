# Pride Engineering Services

A modern, responsive corporate website designed for **Pride Engineering Services LLC**, an engineering solutions company based in Muscat, Oman.

The website presents the company's engineering expertise, refrigeration systems, cold storage solutions, commercial kitchen systems, electromechanical services, projects, and contact information through a clean, premium industrial design.

---

## 🌐 Live Website

**Production:**  
https://pride-engineering-website.vercel.app/

---

## 📌 About the Project

The Pride Engineering Services website was designed with a strong focus on:

- Modern industrial aesthetics
- Clean and professional typography
- Responsive layouts
- High-quality engineering imagery
- Clear service presentation
- Strong visual hierarchy
- Smooth interactions and hover effects
- Consistent brand colors
- Easy navigation and contact access

The visual identity is built around the company's **navy blue, white, and gold** brand palette.

## 🎨 Design System

### Brand Colors

| Color | Usage |
|---|---|
| Navy Blue | Primary backgrounds and headings |
| White | Light backgrounds and typography |
| Gold | Accent color, numbering and CTAs |
| Light Gray | Secondary backgrounds and supporting elements |

The design maintains a consistent navy-and-gold visual identity across dark sections while using white backgrounds for content-heavy sections.
